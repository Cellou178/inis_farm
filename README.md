## Description (Play Store / App Store)

INIS Smart Farm est la première application de gestion avicole intelligente conçue pour les éleveurs de poulets de chair du Sénégal et de l'Afrique de l'Ouest.

Suivez chaque cycle avec précision : pesées, mortalité, consommation d'aliment, IC, GMQ et CV%. L'application calcule automatiquement vos indicateurs de performance et les compare aux standards internationaux COBB 500.

Prenez de meilleures décisions grâce à l'IA : prédiction du poids à J35, recommandation du jour optimal de vente, diagnostic précoce des maladies et alertes automatiques.

**Mots-clés** : aviculture, poulet de chair, élevage, Sénégal, Afrique, ferme, gestion, IC, GMQ, marketplace, Wave, Orange Money

**Catégorie** : Agriculture / Productivité
